# Sorted: Ball Sort Puzzle

This repository contains the official website for **Sorted**, the ball sort puzzle by Tom Appleton. Sorted is built for players who enjoy ball sort but want fewer forced ads, free undo, offline play, and levels checked for a real solution.

- [Official website](https://sortedballsort.com/)
- [Apple App Store](https://apps.apple.com/app/id6759809485)
- [Google Play](https://play.google.com/store/apps/details?id=com.infinitygames.ballsort)

The website explains the exact advertising rules and how the game verifies that each starting board is solvable.
